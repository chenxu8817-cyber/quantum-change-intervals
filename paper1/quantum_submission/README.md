# Quantum submission source

This directory is a self-contained working source package for Paper I.

## Build

Compile main.tex with pdfLaTeX/BibTeX through the repository's documented
LaTeX helper. The official Quantum class version 6.1 and quantum.bst are
vendored here because arXiv submissions must include the class and generated
BBL.

## Draft status

The unpublished class option is intentional. Author names, affiliations, Xu
Chen's ORCID and corresponding-author email, funding, author contributions,
and competing-interest information have been inserted. Verify these fields
before posting to arXiv. After acceptance, follow Quantum's instructions for
the accepted-date class option.

## Figures

The figures directory contains vector PDFs copied from ../figures. They are
regenerated by running paper1_make_figures.py from the repository root.

## Human checks before submission

- Verify author ordering, affiliations, Xu Chen's ORCID and corresponding-author
  email, funding, contribution roles, and competing-interest statement.
- Add Xue Ma's ORCID if one is to be associated with the article.
- Verify that the AI-assisted-tools disclosure accurately describes the final
  scope of tool use.
- Retain the author-approved MIT License for the public code repository.
- Add an archival DOI after an immutable Zenodo or institutional deposit is
  created.
- Include main.bbl in the arXiv source bundle after the final BibTeX run.
