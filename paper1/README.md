# Paper I package

The canonical manuscript is the Quantum-class source in
`quantum_submission/main.tex` and `quantum_submission/content.tex`. Its
scientific scope is one contiguous returning interval with a known pure
anomaly state and arbitrary collective measurements. The file
`quantum_submission/main.pdf` is the corresponding reference build.

The earlier `manuscript.md` file is retained only as a workspace drafting
artifact. It is not a submission source and is intentionally excluded from the
public GitHub upload package and its reproduction manifest. Figures 1--3 are
generated by `../paper1_make_figures.py`.

## Review map

- PROOF_AUDIT.md records the closed mathematical obligations and excluded
  claims.
- NUMERICAL_REPRODUCIBILITY.md records every numerical grid and the safeguarded
  floating-point residual maxima.
- REPRODUCING.md gives the clean CPython 3.12 protocol.
- PUBLIC_RELEASE_CHECKLIST.md records the public-repository/DOI metadata gate
  and the exact archival sequence.
- run_reproduction.ps1 executes tests, all Paper-I numerical grids,
  tolerance-based comparisons, and manifest generation.
- quantum_submission/ contains the official quantumarticle 6.1 class, Quantum
  bibliography style, BibTeX database, generated BBL, and compiled PDF.
- verification_report.json is the machine-readable pass/fail report.
- reproduction_manifest.json stores runtime metadata and SHA256 hashes.

## Data retained for Paper I

- paper1_fixed_and_growing_srm.csv: fixed \(i=2\), square-root growth, and
  balanced growth schedules.
- paper1_h0_certified_sdp.csv: nonuniform-prior no-anomaly primal/dual SDPs.
- ../certified_sdp_results.csv: 30 unknown-length primal/dual SDP checks
  (legacy filename).
- ../srm_scaling_m1.csv: full dense physical-Gram SRM computations through \(n=50\).

Multi-interval data, forest factorizations, and their tests belong to Paper II
and are intentionally absent from this evidence map.

## Remaining human-only submission checks

The manuscript now records the author names, affiliations, corresponding-author
email and ORCID, contribution statement, funding, competing-interest statement,
and public repository URL supplied by the authors. Before submission, the
authors must verify those fields, create the promised versioned archival
release, and complete any venue-specific disclosure. The bibliography should
also receive one final publisher-level metadata check.
